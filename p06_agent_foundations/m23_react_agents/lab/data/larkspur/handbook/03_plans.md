# Plans and server sizes

Larkspur Cloud has three plans. The plan sets how many servers an account can run, how fast support answers and which features are available.

- **Starter** runs up to 3 servers and includes manual snapshots.
- **Business** runs up to 50 servers and adds daily backups and team accounts.
- **Enterprise** has no server limit and adds cross-region backup copies, phone support and a named support engineer.

Any plan can be paid monthly or annually. Annual billing costs the same as ten months of monthly billing.

Choose a server size by peak memory use. Each server plan lists vCPUs, memory and included outbound traffic.

| Size | vCPUs | Memory | Included outbound traffic |
|---|---|---|---|
| Small | 2 | 4 GB | 1 TB per month |
| Medium | 4 | 16 GB | 3 TB per month |
| Large | 16 | 64 GB | 8 TB per month |

You can move a server to a larger size from the console. Resizing restarts the server once. Moving to a smaller size is only possible when the disk in use fits the smaller size.
