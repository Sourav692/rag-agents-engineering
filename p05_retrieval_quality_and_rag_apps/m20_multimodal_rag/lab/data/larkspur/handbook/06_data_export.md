# Data export and retention

Export your data at any time from Settings, then Data. Exports include databases, object storage and server snapshots.

Each export is packaged as one archive per region. Large exports run in the background, and you get an email when the archive is ready. The download link stays valid for 7 days.

After a plan is cancelled, its data is kept for 30 days and then permanently deleted. Export it before that window closes.

Support cannot restore deleted data, so check that the archive opens before the retention window ends.
