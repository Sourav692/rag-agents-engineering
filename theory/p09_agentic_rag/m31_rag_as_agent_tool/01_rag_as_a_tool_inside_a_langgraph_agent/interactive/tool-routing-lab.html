M31 lab, RAG as an agent tool

The description is all the router sees.

An agent has two tools, handbook_search over the Larkspur Cloud handbook and web_search, and twenty mixed questions. Edit either description and every question is routed again. The router here is the M11 TF-IDF retriever pointed at the two descriptions, a stand-in for the model’s choice.

A question that matches neither description gets no tool: the agent answers from its own weights. Equal scores above zero count as a miss. Highlighted words are the ones the question shares with a description. Tokens use the four-characters-per-token rule of thumb.
