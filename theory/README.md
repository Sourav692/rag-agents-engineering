# Theory

> The index is generated by `scripts/build_curriculum.py`. The pages are hand-written: edit `theory/<part>/<module>/README.md` and its lesson folders (see `CLAUDE.md` → Theory pages).

Laid out like `course/`: one folder per module, one subfolder per lesson. A module page has the overview, interview questions and takeaways; each lesson page explains that lesson's concepts with diagrams. Each module's `index.html` joins its pages into one page to read in a browser. Some lessons have interactive labs (single HTML files, open them in a browser).
