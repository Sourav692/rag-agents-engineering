A support agent with one tool, search_handbook, over the twelve Larkspur Cloud chunks from the M11 lab. Retrieval is real TF-IDF, top 2 per search. The model is scripted: it writes the queries a model might write, reads each result, and stops when it has the evidence. Switch the wiring and move the call cap to see what the user receives.
