# Prerequisites

This repository assumes *knowledge* from earlier repositories in the sequence. It never imports their
code, data or packages.

| From | You should be able to | Refresh in |
|---|---|---|
| 01 Foundations | Write Python in notebooks, use virtual environments, read environment variables, call an LLM provider API directly | [repository 01](https://github.com/Sourav692/ai-engineering-demystified-01-foundations) |
| 02 Prompt and context engineering | Write clear, structured prompts and ask for structured output | [repository 02](https://github.com/Sourav692/ai-engineering-demystified-02-prompt-context-engineering) |
| 03 LangChain fundamentals | Use chat models, messages, prompt templates, output parsers and compose Runnables with `\|` (LCEL) | [repository 03](https://github.com/Sourav692/ai-engineering-demystified-03-langchain-fundamentals) |
| 04 LangGraph fundamentals | *Recommended, not required.* Nothing here builds a graph | [repository 04](https://github.com/Sourav692/ai-engineering-demystified-04-langgraph-fundamentals) |

Also useful: basic linear algebra intuition (vectors, dot product, cosine similarity) and familiarity
with Docker for the two PGVector notebooks in module 12 and the Postgres-backed notebook in module 06.
