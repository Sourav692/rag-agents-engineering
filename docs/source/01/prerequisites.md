# Prerequisites

This is the first repository in the course, so it assumes very little.

## Knowledge

- **Required:** comfort with a terminal — changing directories, running commands, editing a text file.
- **Helpful for modules 04–05:** knowing what an HTTP API and an API key are. Module 02 introduces both.
- **Helpful for modules 07–08:** a rough idea of what a neural network is and what "training" means. Module 06 (planned) will cover the intuition; until then any introductory ML overview is enough.

No prior Python is assumed: module 01 starts from variables.

## Accounts (only for the modules that call hosted services)

| Account | Needed for |
|---|---|
| OpenAI API | Module 04 notebook 01, module 05 |
| Google AI Studio (Gemini) | Module 04 notebook 01, optional half |
| Hugging Face | Module 04 notebooks 02–03, module 07, module 08 notebook 07 |
| Lamini | Optional for module 08 — the labs run offline without it |

## Hardware

Modules 01–05 run on any laptop. The diffusion, video and larger audio notebooks in module 07, the local-LLM notebook in module 04 and the AutoTrain notebook in module 08 need a GPU (they were written for Google Colab GPU runtimes).
