# Curriculum map

Module → notebook → learning objective, in learning order.

| Module | Notebook | Learning objective |
|---|---|---|
| 01 Prompting basics | [01_prompt_engineering_patterns](../modules/01_prompting_basics/notebooks/01_prompt_engineering_patterns.ipynb) | Apply the persona, flipped-interaction, N-shot, directional-stimulus, template and meta-language prompt patterns. |
| 02 Advanced prompt patterns | [01_advanced_prompt_engineering_patterns](../modules/02_advanced_prompt_patterns/notebooks/01_advanced_prompt_engineering_patterns.ipynb) | Use chain-of-thought, self-consistency, least-to-most and ReAct-format prompting for multi-step reasoning. |
| 03 Model-specific practice | [01_openai_gpt_4o_mini](../modules/03_model_specific_practice/notebooks/01_openai_gpt_4o_mini.ipynb) | Prompt GPT-4o-mini through the OpenAI client for ten everyday tasks. |
| 03 Model-specific practice | [02_google_gemini_1_5_flash](../modules/03_model_specific_practice/notebooks/02_google_gemini_1_5_flash.ipynb) | Prompt Gemini 1.5 Flash through the Google GenAI client for the same ten tasks. |
| 03 Model-specific practice | [03_meta_llama_3_2_90b_groq](../modules/03_model_specific_practice/notebooks/03_meta_llama_3_2_90b_groq.ipynb) | Prompt an open-weight Llama 3.2 90B model served by Groq for the same tasks. |
| 03 Model-specific practice | [04_meta_llama_3_2_1b_huggingface](../modules/03_model_specific_practice/notebooks/04_meta_llama_3_2_1b_huggingface.ipynb) | Prompt a small language model (Llama 3.2 1B) through the Hugging Face Inference Client. |
| 04 Multimodal prompting | [01_multimodal_google_gemini](../modules/04_multimodal_prompting/notebooks/01_multimodal_google_gemini.ipynb) | Prompt Gemini with images, PDFs, audio and video, separately and together. |
| 04 Multimodal prompting | [02_multimodal_openai_gpt_4o](../modules/04_multimodal_prompting/notebooks/02_multimodal_openai_gpt_4o.ipynb) | Prompt GPT-4o with base64 and URL images, and summarize a video from sampled frames plus its transcript. |
| 04 Multimodal prompting (exercise) | [01_financial_report_analysis](../modules/04_multimodal_prompting/exercises/01_financial_report_analysis.ipynb) | Write a multimodal prompt that summarizes a financial report from images of its pages. |
| 05 Context engineering | [README](../modules/05_context_engineering/README.md) | 🚧 Planned: assemble and budget the context window. |
| 06 Applied prompting | [01_gpt_4o_and_llama_3_2_real_world_tasks](../modules/06_applied_prompting/notebooks/01_gpt_4o_and_llama_3_2_real_world_tasks.ipynb) | Combine the patterns on five business tasks and compare GPT-4o with Llama 3.2 90B. |
