# Source reference

The prompt-engineering notebooks in this repository began as the standalone **Prompt Engineering Demystified** collection: hands-on Jupyter notebooks covering prompt engineering patterns, techniques and real-world applications across OpenAI GPT-4o, Google Gemini and Meta Llama 3.2. That collection was merged into the `AI-ENGINEERING-DEMYSTIFIED` monorepo and regrouped by technique, and is now extracted here. The notebooks keep their original author credit (Dipanjan (DJ)) where the source had one.
