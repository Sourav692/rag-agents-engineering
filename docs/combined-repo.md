# Combined Course Repo

> Generated by `scripts/build_docs.py` from `curriculum.yaml`. Do not edit by hand. See [CLAUDE.md](../CLAUDE.md).

The 9 *AI Engineering Demystified* source repos (01, 02, 03, 04, 05, 06, 08, 09, 10) combined into one public course repository, `Sourav692/rag-agents-engineering`, organised by the RAG & Agents Engineering curriculum.

**Status: built and in use.** 14 parts · 46 modules · 381 notebooks (210 mandatory, 171 optional) · about 216 h. Operating model: **Option A**, this repo canonical.

## Decision

**Built from the source repos with a migration script, then made canonical (Option A, 1 Nov 2026).** Notebooks, helpers and data are edited here; the source repos are archived.

### What the combined repo gives

- **One learning path.** 14 parts and 46 modules in syllabus order, from Python & Data Toolkit Refresher (M01) to Architecture Synthesis: Choosing a System Design (M46).
- **Tiers visible on disk.** mandatory/notebook/ holds the 210 mandatory notebooks; optional/notebook/ and projects/ hold the other 171.
- **One environment.** One uv lock and one .env.example; conflicting stacks are separate dependency groups declared as uv conflicts.
- **Every notebook placed once.** All 381 notebooks from the 9 source repos sit in exactly one lesson; the tests enforce it.
- **Course-only content.** Module labs, 4 capstones, an interactive syllabus and a provenance CSV that the topic repos never had.

### How the risks were handled

- **Two copies of every notebook.** Option A: this repo is canonical. The last "Sync from source repos" commit names the final source SHAs, and the nine source repos are archived with a pointer here.
- **Paths and imports move.** migrate.py rewrites ../../../data|src|docs to the new depth, rewrites links and %run targets, and copies companion .py files beside each notebook so imports work unchanged.
- **Mixed licences.** NOTICE.md lists every third-party file; the licence texts are kept in docs/third_party/.
- **Visibility.** The course repo is public; the source repos it was built from are archived.
- **Provenance.** docs/content-inventory.csv maps every one of the 995 copied files to its source repo and path.
- **Dependency clashes.** pandas pinned >=2.2 for llama-index; colpali, finance and the protocol SDKs isolated as conflicting groups.
- **Drift in reference docs.** Module numbers and paths in CURRICULUM.md, NOTICE.md and these docs are rendered from curriculum.yaml, and CI fails when they are stale.

### Conventions

- **Folders follow the syllabus:** `pNN_<part>/mNN_<module>/` at the repo root, numbered M01 to M46 as in the curriculum.
- **Tiers are folders:** `mandatory/notebook/` is the mandatory track; `optional/notebook/` holds alternate, platform-specific, extension and exercise notebooks; `projects/` holds runnable MCP sub-projects. Theory pages sit in `mandatory/theory/` and `optional/theory/` by the same rule.
- **File names carry the lesson:** `03b_parallelization_sectioning_and_voting.ipynb` is lesson 3, second item, so a lesson's mandatory and optional notebooks sort side by side.
- **Every module has README.md and lab/:** the README is generated from `curriculum.yaml`; `lab/README.md`, `lab/solution/` and `lab/data/` are hand-maintained.
- **Provenance:** `docs/content-inventory.csv` maps every copied file to its source repo and path; source docs are archived under `docs/source/<key>/`.

## Migration plan

1. **Done.** Turn the curriculum into curriculum.yaml: parts, modules, lessons, every source file with its tier and destination.
2. **Done.** Write scripts/migrate.py: copy and rename every file, record old path → new path in docs/content-inventory.csv.
3. **Done.** Bring shared code into src/ and keep helper imports working (companion files beside notebooks; src/helpers deduplicated).
4. **Done.** Fix paths for the new depth: the ../../../data references, docs links, notebook links and %run targets.
5. **Done.** Merge the source repos' pyproject.toml dependency sets and .env.example files; run uv lock.
6. **Done.** Port the checks: manifest, notebook JSON validity, stale paths, link check; CI on every push.
7. **Done.** Generate READMEs, CURRICULUM.md, NOTICE.md, the interactive syllabus and these reference docs from curriculum.yaml.
8. **Done.** Decide the source repos' future: Option A since 1 Nov 2026. After a final sync, this repo is canonical and the nine source repos are archived with a pointer here.

### What changed from the original proposal

- Scope grew from four source repos (05, 06, 08, 09; 251 notebooks, 31 modules) to nine (01–06, 08–10), adding the foundations, prompting, LangChain/LangGraph and agent-protocol Parts.
- Companion files were copied beside their notebooks, so notebooks stay identical to the source apart from path rewrites. After the switch to Option A, the 24 copies each of helper_functions.py and evalute_rag.py became one-line shims over src/rag_techniques/.
- Paths are rewritten to the new depth rather than routed through a data_dir() helper, for the same reason.
- Lessons whose companion files would clash get per-lesson subfolders (the fine-tuning lessons use mandatory/notebook/05_training and similar).
- MCP sub-projects keep their source names under projects/, because repo 10 notebooks write into ../projects/<name>/.
